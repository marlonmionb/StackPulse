# Content Kind

Classifies the editorial/source nature of technically relevant, non-video
SourceItems with `gpt-5.4-nano` through the shared observable AI boundary.
Results use a controlled taxonomy and confidence enum, strict Structured Outputs,
transactional persistence, skip-by-default caching, deliberate `--force`
re-evaluation, and successful-metadata-enrichment freshness invalidation.

This module does not redefine Content Type, determine Technical Relevance,
fetch page bodies, perform Topic Discovery, or implement Topic Research.
